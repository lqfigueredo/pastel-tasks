---
name: kanban-types-and-logging
description: Centralized Kanban types in src/types/kanban.ts; task change logs are auto-generated by DB triggers.
type: feature
---
- Tipos `Task`, `TaskStatus`, `Profile` ficam em `src/types/kanban.ts`. Hooks e componentes devem importar dali. `AssigneeSelector` re-exporta `Profile` por compatibilidade.
- Ordem das colunas é gerenciada por `useColumnOrderQuery`/`useUpdateColumnOrder` (hooks com cache + optimistic update). Não fazer fetch direto a `user_column_order`.
- `task_change_logs` é populado automaticamente por triggers Postgres (`trg_log_task_changes` em `tasks`, `trg_log_task_assignee_changes` em `task_assignees`). Nunca inserir manualmente do client; o trigger usa `auth.uid()` e ignora chamadas via service role.
- Campos rastreados pelo trigger de tasks: title, description, status, start_date, estimated_delivery_date, actual_end_date, is_critical.
